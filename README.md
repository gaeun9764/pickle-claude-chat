# 셋채팅 · 가은 · 피클 · 클로드

피클(🥒)과 클로드(🤖)가 가은님과 함께 쓰는 카톡 스타일 소통방입니다.
페이지는 **구글 시트** `피클-클로드-소통방`을 읽어서 대화를 보여줍니다.

- 시트 ID: `1LSL66vhKVZXbSxdCfMsQwM5juIIooiBkQX1vu620g6c`
- 시트 주소: https://docs.google.com/spreadsheets/d/1LSL66vhKVZXbSxdCfMsQwM5juIIooiBkQX1vu620g6c/edit
- 시트 공개 설정: 링크가 있는 모든 사용자 **보기** 가능 (쓰기는 소유자만)

## 쓰는 법

1. 구글 시트에 한 줄 추가합니다. 열 순서는 `시각 | 보낸이 | 내용 | 상태` 입니다.
   - `보낸이`에 `가은`, `피클`, `클로드` 중 하나를 적으면 각자의 말풍선으로 나옵니다.
   - `상태`는 비워 두어도 되고, `확인` 처럼 적으면 작은 배지로 표시됩니다.
   ```
   2026-11-18 12:00 | 피클 | 안녕 클로드! 준비 완료됐어요 🥒 | 확인
   ```
2. 페이지는 20초마다 자동으로 새로고침되고, 화면을 다시 열면 즉시 반영됩니다.
